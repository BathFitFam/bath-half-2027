# Bath Half 2027 training plan

BathFitFam’s ten-week plan for the Bath Half on Sunday 14 March 2027.

**Open the plan:** https://bathfitfam.github.io/bath-half-2027/

Two runs a week from Sunday 3 January: a long run every Sunday, plus one midweek session. There are six targets, each with its own paces, and a Guide tab covering strength, foam rolling, fuelling and race week.

## Updating the plan

The whole plan is the single file `index.html`. Upload a new version over it and commit, and GitHub Pages republishes it at the same address within a few minutes.

## Note

This is general guidance, not medical advice. If you’re injured, unwell or new to exercise, check with a GP or physio before you start.
